Used here as CHECK DATA only: the OpenType layout reader (Rasterizer/OpenTypeLayout.cs) and
the Indic shaper (TextShaping/IndicShaper.cs) are exercised against their GSUB/GPOS/GDEF
tables, with expectations produced from the same files by independent tools (fontTools,
HarfBuzz — see tools/shaping-oracle/). The fonts are not shipped with the mod by this project.
Glyph ids in the expectations are those of these exact files: replacing a font means
regenerating TestData/Shaping/ with the oracle.
